# AR Tracing

그림 연습할 때 쓰려고 만든 Android 앱입니다. 카메라 화면 위에 참고 이미지를 띄워 놓고, 화면을 보면서 종이에 따라 그릴 수 있습니다.

[APK 다운로드](https://github.com/gunmin20/AR-Tracing/releases/latest) · [문제 제보](https://github.com/gunmin20/AR-Tracing/issues/new?template=bug_report.md)

## 설치

Android 7.0 이상, 후면 카메라가 있는 기기에서 사용할 수 있습니다.

릴리스 페이지의 **Assets**에서 `.apk` 파일을 받아 설치하면 됩니다. 설치가 차단되면 다운로드한 앱의 ‘알 수 없는 앱 설치’를 허용해 주세요. 처음 실행할 때 카메라 권한도 필요합니다.

`SHA256SUMS.txt`는 파일 확인용 체크섬입니다. 앱을 설치할 때는 APK만 받으면 됩니다.

## 사용법

1. 휴대폰을 거치대에 고정하고 카메라가 종이를 비추도록 놓습니다.
2. **이미지 선택**을 눌러 따라 그릴 이미지를 불러옵니다.
3. 한 손가락으로 위치를 옮기고, 두 손가락으로 크기와 각도를 조절합니다.
4. 하단 슬라이더로 투명도를 맞춥니다.
5. 오른쪽 위 메뉴에서 **잠금**을 켜고 그리면 됩니다.

같은 메뉴에서 **십자선**을 켜거나 끌 수 있습니다. 잠금을 다시 누르면 이미지를 움직일 수 있습니다.

잠금은 이미지 터치 조작만 막습니다. 휴대폰이나 종이가 움직이면 위치를 다시 맞춰야 합니다. 종이에 빛을 쏘는 프로젝터나 공간을 추적하는 방식은 아닙니다.

## 참고

- 화면을 회전하거나 앱을 다시 열면 이미지와 조정 상태가 초기화됩니다.
- 사진 촬영, 그림 저장, 자동 윤곽선 추출은 지원하지 않습니다.
- 카메라 권한은 미리보기에 사용합니다. 앱에 인터넷 권한은 없으며, 선택한 이미지를 업로드하지 않습니다.
- 기기에 저장된 이미지를 사용하면 인터넷 연결 없이 쓸 수 있습니다.
- 이번에 배포한 `v1.0.0` APK는 빌드와 서명 검증을 마쳤지만, 실기기 테스트는 아직 하지 않았습니다.

카메라가 안 나오면 휴대폰 설정에서 카메라 권한을 확인해 주세요. 이전 개발용 APK와 서명이 달라 설치되지 않는 경우에는 기존 앱을 삭제한 뒤 설치해야 합니다. 이때 기존 앱 데이터도 삭제될 수 있습니다.

문제가 있으면 [Issues](https://github.com/gunmin20/AR-Tracing/issues)에 기기명, Android 버전, 앱 버전과 문제가 생긴 상황을 남겨 주세요.
